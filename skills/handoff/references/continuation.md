# Resume or pause work

Read this when the user requests pickup of an unfinished task or an explicit pause. Ordinary handoff requests need only the main skill. A continuation note preserves context; it does not authorize execution by itself.

## Pick up from evidence

Use the current conversation, supplied handoff, relevant task plan, and decision trail first. Read applicable repository instructions and inspect the referenced workspace, branch, HEAD, and local changes. Compare the current artifacts with the prior note. Treat prior decisions as context to preserve and verification claims as evidence tied to their original state.

Identify completed work, pending units, unresolved dependencies, and the first useful action. Distinguish confirmed publication or delivery from local changes. Do not repeat completed work merely because a new session started. Recheck where the artifact changed, evidence is missing, or a consequential claim must be established before relying on it. Explain any material discrepancy between the note and current state.

Use only relevant supplied or authorized project history. Do not invent a transcript location or search unrelated sessions to fill gaps. If a required note or artifact is unavailable, state the specific gap and reconstruct what current evidence supports.

If the request asks only for a resume summary, return the resume point and stop. If it requests continued work, follow the appropriate Pancake workflow within existing authorization. A proposed next action in an old note is not approval for a new external write or expanded scope. Preserve known user constraints and use current steering when it changes the plan.

## Pause without losing context

An explicit pause stops new task work. A request to keep working while the user is away is not a pause. Tell active task-owned workers to stop writes when host collaboration supports it, inspect the resulting state, and report any worker that could not be stopped. Do not spawn workers merely to follow this guidance.

Record incomplete operations, pending external actions, task-owned processes or resources, and known state. Do not assume an armed merge or remote job was canceled because the local task paused. Report what is still active; cancel remote actions only with authorization covering that change. Interrupt an ongoing task-owned local operation where supported without deleting partial artifacts or altering unrelated resources.

Preserve existing local edits and useful evidence. Do not commit, stash, reset, roll back, push, clean resources, or complete another implementation unit just to leave a tidy workspace. State if the current tree is incomplete or unverified. A pause is not a completion verdict.

Return the proportional handoff described by the main skill, with the exact resume point and relevant artifact locations. Save it only when requested, using the requested destination. Never claim context is durable in a file when it exists only in the conversation. On later resumption, inspect current state before relying on the pause note.
