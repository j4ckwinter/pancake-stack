# Say it plainly

Rewrite the previous substantive assistant answer. If the user identifies a particular passage, rewrite that passage instead. Ignore tool output and skill-loading acknowledgements when choosing the answer to restate.

Lead with the point. Use everyday words and concrete descriptions of what happens or what the user needs to do. Explain an essential technical term briefly rather than replacing it with a vague metaphor.

Keep the meaning, important caveats, uncertainty, and any action the user needs to take. Preserve useful commands, identifiers, and source links exactly. Shorten the explanation without turning an inference into a fact or a proposed action into completed work.

Use a short paragraph unless a few bullets make the answer easier to follow. Match the user's level of detail. Do not add a preamble, apology, lecture, or commentary about the original wording.

Rephrase from the conversation. Do not start a new investigation or use tools merely to simplify the answer. Do not invent supporting facts. If the original answer contains an obvious factual mistake, briefly identify the correction instead of repeating it as true.

If no previous answer or passage is available, ask the user which text to simplify.
